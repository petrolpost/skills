# 速览卡规范（分类 + 打分 + 概要）

速览卡是用户的**决策工具**：分类回答"这是什么领域的什么文章"，打分回答"值不值得花深读的力气"。

## 行业分类

**主行业单选**，按"文章试图解决的问题所处的领域"判定（而非作者背景或发表渠道），可另加不超过 2 个副标签。分类表：

| 编号 | 行业 |
|------|------|
| 1 | 企业管理（战略/组织/人力/领导力/运营） |
| 2 | 科技与人工智能 |
| 3 | 金融与投资 |
| 4 | 营销与增长 |
| 5 | 医疗健康 |
| 6 | 制造与供应链 |
| 7 | 能源、环境与可持续 |
| 8 | 公共部门与政策 |
| 9 | 教育 |
| 10 | 消费与零售 |
| 11 | 媒体、娱乐与内容 |
| 12 | 跨领域/通用（方法论、思维、个人成长） |

跨领域文章取核心问题所在行业为主行业，其余进副标签。无法归入 1–11 的通用方法论文章归 12。

## 文章分型

**主类型单选**，按文章主体结构与写作意图判定；特征混合时按主体占比判定并注次类型。类型表与判定规则：

| 类型 | 判定信号 |
|------|---------|
| 实证研究 | 有样本/数据/方法论，结论来自系统性证据（论文、数据报告） |
| 实务观点 | 作者基于经验论证某个主张，观点输出、论证驱动 |
| 实操指南 | 主体是步骤、框架、清单、最佳实践，处方性（how-to） |
| 趋势预测 | 关于未来的判断与情景推演 |
| 新闻报道 | 事件驱动的事实性报道 |
| 案例研究 | 围绕单一/少数案例的深度剖析 |
| 访谈/对话 | 问答体 |
| 书评/作品评论 | 围绕一部作品的评价 |

判定顺序：有方法论和数据 → 实证研究；主体规定动作步骤 → 实操指南；主体论证主张 → 实务观点；主体推演未来 → 趋势预测；主体报道事件 → 新闻报道。

## 五维打分

每维 1–5 分，**每一分档都必须给一句话理由**，不允许只给数字。锚点定义：

**① 观点新颖度**
- 5：提出新概念/新框架，有重新定义问题的潜力
- 4：对已知问题给出明显不同的新视角
- 3：对已有观点的重组或细化，有增量
- 2：主流共识的换皮
- 1：陈词滥调

**② 证据强度**
- 5：大样本实证或多项权威数据
- 4：多个真实可查证的案例 + 专家佐证
- 3：个别案例，典型但不可量化/不可查证（含匿名案例）
- 2：纯推理，无案例无数据
- 1：断言式，无任何支撑
- **封顶规则**：全文无任何数据与真实案例 → 本维最高 2 分。

**③ 实用性**
- 5：可直接执行的步骤/清单/测量工具
- 4：有较具体的操作指引，稍加转化可落地
- 3：方向性启发，需自行转化
- 2：仅认知层面启发
- 1：无行动接口

**④ 可信度** = 发表渠道 × 作者相关资历
- 5：同行评议期刊 / 权威实务渠道（HBR、顶级咨询机构报告等）+ 相关领域资深作者
- 4：权威渠道 + 资历一般，或普通渠道 + 资深作者
- 3：普通行业媒体，作者背景与主题相关
- 2：自媒体但作者为相关从业者
- 1：来源不明或作者无相关背景

**⑤ 时间性价比** = 信息密度 ÷ 篇幅
- 5：短小精悍，几乎无水词
- 4：紧凑，冗余少
- 3：中等密度
- 2：明显注水，可压缩 1/3 以上
- 1：大量填充

## 总分与深读建议

总分 = 五维之和（5–25），映射：

| 总分 | 建议 |
|------|------|
| ≥ 20 | 强烈建议深读 |
| 15–19 | 建议深读 |
| 10–14 | 速览即可 |
| < 10 | 不建议花时间 |

**调整规则**：任何一维 ≤ 1 分，总分档位下调一级（如"建议深读"→"速览即可"）。

**诚实性规则**：打分是研读者的判断，必须逐维说明理由；不得为推荐深读而抬分，也不得因文章内容不合口味而压分。

## 速览卡输出模板

```markdown
## 全文速览卡

### 分类
- **行业**：{主行业}（副标签：{…}）
- **分型**：{主类型}（次类型：{…}）— {一句话判定依据}

### 打分
| 维度 | 分数 | 理由 |
|------|------|------|
| 观点新颖度 | x/5 | {一句话} |
| 证据强度 | x/5 | {一句话} |
| 实用性 | x/5 | {一句话} |
| 可信度 | x/5 | {一句话} |
| 时间性价比 | x/5 | {一句话} |
| **总分** | **xx/25** | **{档位建议}** |

### 概要
- **写作意图**：{一句话}
- **目标读者**：{画像}
- **核心论点**：{1–3 条}
- **核心资源**：{关键工具/书籍/人物/概念/链接}
- **主要可输出产物预告**：{深读后可沉淀的 Artifacts}
- **点评模式预判**：{red_team / socratic / collaborative} — {一句话理由}
```
