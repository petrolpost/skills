### 评分锚点（Agent 内部打分标准）

| 维度  | ✅ 健康（1分） | ⚠️ 注意（0分） | ❌ 严重（0分） |
| --- | --- | --- | --- |
| 可回溯性 | 仍能解释 Step 0 且更统一 | 关联变弱但不矛盾 | 完全偏离或无法判断 |
| 版本稳定性 | 有明确 SR 且地基已压实 | 仅有 WD 或最近无发布 | 核心概念仍在频繁变动 |
| 闭环与证据 | 闭环存在且有证据指针 | 有实现但无证据指针 | 单向流动或完全断裂 |
| 可积累性 | 有 Release 且记录假设验证 | 有 Release 但未记录原因 | 无 Release，持续无限推演 |
| 概念漂移 | 假设有效，概念含义一致 | 含义模糊或边界歧义 | 假设失效或概念关系混乱 |

**Decision: [PASS / PASS WITH DEBT / REVISE / BLOCK]**
（评分映射：5/5→PASS，3-4/5→PASS WITH DEBT，1-2/5→REVISE，0/5→BLOCK）

## 模式 D：阶段导航模板

*触发条件：用户询问"现在该做什么"或"项目处于什么阶段"。*

```textile
────────────────────────────────────────────────
    阶段导航
────────────────────────────────────────────────
📍 当前阶段：{Discovery / Expansion / Conflict / Compression / Release / Observation}
🔄 阶段特征：{该阶段的典型特征描述}
🎯 核心任务：{该阶段应该聚焦什么}
⚠️ 常见陷阱：{该阶段容易犯什么错误}
▶️ 下一步建议：{具体应该做什么}
────────────────────────────────────────────────
```

**Decision: [PASS / PASS WITH DEBT / REVISE / BLOCK]**
（基于阶段判断：可推进→PASS，需先处理债务→PASS WITH DEBT，需巩固→REVISE，有关键问题→BLOCK）
